# Brand assets

- `mark.svg` and `mark-dark.svg` contain the custom geometric mmd2pptx mark.
- `logo.svg` and `logo-dark.svg` combine that mark with an outlined wordmark.
- The wordmark outlines were generated from [Nunito](https://github.com/googlefonts/nunito) at weight 725, then fitted to the approved artwork. Nunito is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
- The SVG files contain the final vector outlines and have no runtime font dependency.
- `avatar.png` is the raster avatar export of `mark.svg`.
